# แผนการพัฒนาหน้าบริการโมเดลและงานอาร์ต (แทนที่ /arts เดิม)

เปลี่ยนผ่านจากหน้า `/arts` แบบเดิมสู่หน้า **VTuber Model Commission & Creative Studio** เต็มรูปแบบ โดยนำข้อมูลจริงที่ได้ (เรทราคา 3 แพ็กเกจ, ส่วนเสริม ACC, สิทธิพิเศษผ่อนชำระ 7 เดือน, ระยะเวลา, ระบบรหัสคิวงาน และเงื่อนไขการจ้าง) มาสร้างเป็นหน้าบริการระดับพรีเมียม

---

## 1. ข้อเสนอการเปลี่ยนชื่อ URL และเมนู Navigation

เพื่อให้สื่อความหมายตรงตัวกับบริการที่รับทำจริง (ซึ่งเป็นงานทำโมเดล Live2D และคอมมิชชันคุณภาพสูง ไม่ใช่แค่หอศิลป์ภาพวาดทั่วไป):

| ตัวเลือก | URL Route | ข้อความใน Navbar | จุดเด่น |
|---|---|---|---|
| **ตัวเลือกที่ 1 (แนะนำ)** | `/commissions` | **Commissions** (หรือ "สั่งทำโมเดล") | ตรงตัวที่สุดในวงการ VTuber & ครีเอเตอร์ ใครเห็นก็เข้าใจทันทีว่าคือหน้ารับงานและเช็กราคา |
| **ตัวเลือกที่ 2** | `/studio` | **Studio** (หรือ "Atelier") | เข้ากับชื่อ *KENELIX STUDIO* ให้ภาพลักษณ์สตูดิโอผู้ผลิตและพันธมิตรสร้างสรรค์ |
| **ตัวเลือกที่ 3** | `/services` | **Services** | เป็นทางการ เหมาะกับลูกค้าองค์กรและแบรนด์ที่ต้องการจ้างงานแบบ B2B |

*(หมายเหตุ: เราสามารถทำ redirect จาก `/arts` เดิมมายัง URL ใหม่นี้ได้อัตโนมัติ เพื่อไม่ให้ลิงก์เก่าเสีย)*

## 3. สิ่งที่เว้นพื้นที่ไว้รองรับข้อมูลเพิ่มเติมในอนาคต
1. **คำอธิบายสเปกความต่างของ Tier 1 / 2 / 3**: ออกแบบกล่อง Tooltip/Info badge รองรับไว้ เมื่อได้คำตอบจะนำมาใส่ทันที
2. **บริการงานเสียง / ภาพประกอบฉาก**: ทำเป็นหมวดเสริม (Optional Add-on) ที่สามารถเปิดสวิตช์แสดงผลได้เมื่อพร้อม
3. **รูปภาพผลงานจริง**: ใส่โครงสร้างและป้ายกำกับเตรียมพร้อม เมื่อได้รับไฟล์ภาพ/คลิป สามารถนำมาวางได้ทันที

## 4. แผนการตรวจสอบ (Verification Plan)
- ตรวจสอบความถูกต้องของตัวเลขราคาทุกช่องในตาราง (Tier 1-3 และ Accessory ของทั้ง 3 แพ็กเกจ)
- ทดสอบระบบสลับแท็บแพ็กเกจ (Half Body / Simple Full / Full Body) ทั้งบนจอเดสก์ท็อปและมือถือ
- ตรวจสอบความลื่นไหลและสีสันที่กลมกลืนกับธีมหลักของ WINEST
- รัน `npm run build` เพื่อการันตีว่าโค้ดคอมไพล์ผ่าน 100%
